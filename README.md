# AI 사용 기록 (AI Usage Record)
1. AI에게 맡긴 일: React 컴포넌트 구조화(Navbar, Hero, About, Experience, Contact, Footer) 및 Tailwind CSS 기반 반응형 UI / 다국어(KO/EN) 인터페이스 구축
2. 내가 판단한 일: 포트폴리오 개인정보 보호를 위한 AES-256-GCM 암호화 방식 채택, 언어와 포트폴리오 구성 설계
3. AI 말을 안 들은 일: AI가 추천한 소스코드 주석 내 비밀번호 기재 방식을 거부하고 주석을 제거함

### 1. 결함 1: 소스코드 주석 내 비밀번호 노출 결함 (보안 결함)
- 수정 전: 소스코드 주석에 비밀번호(`fortytwo`)와 성명(`강아름`)이 평문 텍스트로 기재되어 브라우저 F12 개발자 도구를 통해 비밀번호가 노출되는 보안 문제 발생.
- 수정 후: 소스코드 주석에서 모든 평문 비밀번호 및 인적사항 삭제.

### 2. 결함 2: 1366×768 / 1920×1080 해상도 가로 넘침(Horizontal Overflow) 및 레이아웃 깨짐 결함
- 수정 전: 핵심 역량 상세 텍스트가 단일 통문장으로 표출되어 1366×768 해상도에서 화면 높이를 초과하거나 가로 스크롤(Overflow-x)이 발생할 위험 요소 존재.
- 수정 후: Tailwind CSS `grid-cols-1 sm:grid-cols-3` 3칸 카드 레이아웃 적용 및 반응형 브레이크포인트 최적화. 1366×768 및 1920×1080 두 해상도에서 첫 화면 스크롤 없이 핵심 요소가 보이고 가로 넘침(Horizontal Overflow) 0건 달성.

### 3. 결함 3: Light 모드 전환 시 헤드라인 타이포그래피 가독성 및 경력 뱃지/태그 대비 결함
- 수정 전: 라이트 테마 전환 시 메인 헤드라인의 투명 그라데이션 기법으로 인해 글씨가 너무 옅게 보이거나, 경력 요약 섹션의 근무 기간 뱃지/기술 스택 태그가 어두운 배경으로 표출되어 가독성 저하.
- 수정 후: `index.css`에 Light 모드 전용 타이포그래피 규칙(`h1`, `h2`, `h3` 딥 슬레이트 블랙 `#020617` 적용) 및 경력 요약 전용 브라이트 뱃지/태그 커스텀 CSS 규칙 적용 완료.
